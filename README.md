## 网站功能

- 实时关键词搜索（企业名、产品、城市、行业）
- 按国家/地区筛选
- 按形态筛选（双足 / 轮式 / 四足 / 双臂）
- 按阶段筛选（量产 / 试点 / 研发）
- 点击表头排序
- 点击企业名查看详细信息（团队背景、融资、出货量等）
- 响应式设计（支持手机和平板）

## 数据字段

| 字段 | 说明 |
|------|------|
| name | 企业名称（中文+英文） |
| country | 国家/地区 |
| city | 所在城市 |
| product | 代表产品 |
| year | 成立年份 |
| type | 产品形态 |
| stage | 商业化阶段 |
| sector | 应用领域 |
| team_bg | 团队背景 |
| funding | 融资/估值 |
| shipment | 2025 年出货量 |
| website | 官网 |

## 技术栈

- 纯静态 HTML + CSS + Vanilla JavaScript
- 数据存储为 JSON
- 托管于 GitHub Pages（免费）
